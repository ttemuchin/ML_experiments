сигнал — это физическая величина, изменяющаяся во времени (или в пространстве) и несущая в себе информацию

В чем разница между аудиосигналом и другими?
Ключевые различия лежат в:

Физической природе: Аудиосигнал — это изменение давления воздуха (в оригинале) или электрического напряжения (после микрофона). 
Другие сигналы могут быть световыми (изображение), электромагнитными (радио), механическими (вибрация) и т.д.

Воспринимающем органе: Аудиосигнал предназначен для слуховой системы человека/животного. 
Это накладывает жесткие ограничения на его частотный диапазон (20 Гц — 20 кГц) и динамический диапазон (громкость). 
Зрительный сигнал (изображение) предназначен для глаз и имеет другие характеристики (разрешение, цветовая гамма).

Методах обработки: Для анализа и обработки аудио используются специфические методы, учитывающие психоакустику 
(например, сжатие MP3). Для изображений — методы, учитывающие особенности зрения 
(например, чувствительность к яркости больше, чем к цвету, что используется в JPEG).

В чем особенность аудиосигнала?
Звук принципиально развернут во времени. Его нельзя воспринять "целиком" мгновенно, как изображение. 
Это требует потоковой обработки в реальном времени.

Классификация форматов
1. Несжатые (RAW) форматы
WAV (Waveform Audio File Format) - самый распространенный, для ml инструментов подходит идеально
Структура: Заголовок + "сырые" PCM-данные (массив значений амплитуды)
Размер относительно велик

AIFF (Audio Interchange File Format)
Аналог WAV от Apple

FLAC (Free Lossless Audio Codec) - Сжатие без потерь 
Качество как у WAV, но размер в 2-3 раза меньше
Алгоритмическое сжатие (как ZIP для аудио), восстановление 100% исходных данных
Требует декодирования перед обработкой

2. Сжатие с потерями (Lossy)
MP3 (MPEG-1/2 Audio Layer III) -  Первый массовый lossy-формат
Частотное маскирование, критическая полосы слуха
Проблемы для ML: Артефакты сжатия (pre-echo, metallic sound) могут мешать моделям

AAC (Advanced Audio Coding) - улучшенный MP3
Более эффективный алгоритм (лучше качество при том же битрете)
Лучшая обработка высоких частот, меньше артефактов

Opus - современный лидер, Лучший кодек для реального времени (чат, стриминг)
Отличное качество даже при низких битрейтах, малая задержка

3. Адаптивные и потоковые форматы
M4A (MPEG-4 Audio)
WebM - веб-ориентированный
AC3 (Dolby Digital)
DTS (Digital Theater Systems)

4.Спец
WMA (Windows Media Audio) - Конкурент MP3 в 2000-х
APE (Monkey's Audio) - Высокая степень сжатия без потерь (лучше чем FLAC)
- но очень ресурсоемкое кодирование/декодирование

Для обучения моделей WAV/FLAC. Для продакшена - обрабатывать все популярные форматы, конвертируя их в единое внутреннее представление. 
Opus и AAC сейчас важнее MP3 для современных приложений.

# Принцип CTC:
# Выход модели: распределение по символам для каждого временного шага
# Специальный токен "blank" (∅) для выравнивания
# Пример выравнивания:
Аудио:      [   |   |   |   |   |   |   ]  # 7 временных шагов
Выход:      [∅|∅| h|∅| e| l| l|∅| o|∅]  # 10 шагов модели

ASR + ФОНЕМЫ
Что такое фонемы?
Фонемы — минимальные смыслоразличительные единицы языка. Русский: ~40 фонем, английский: ~44.

Почему фонемы важны?
Проблема с прямым аудио->текст:
"cat" и "kat" (опечатка) → совершенно разные последовательности
С фонемами:
"cat" → /k/ /æ/ /t/
"kat" → /k/ /æ/ /t/  # те же фонемы!

Плюсы:
1. Акустически стабильнее чем слова
2. Разделение акустической и языковой модели
3. Меньше размер словаря (40 vs 50K+ слов)

Современный подход: Phoneme-Based ASR
# Архитектура:
audio → encoder → phoneme_probabilities (41 классов) → decoder → text
# Преимущества:
1. Меньше данных: 100 часов для фонем vs 1000 часов для слов
2. Лучшая обобщающая способность для редких слов
3. Легче внедрить языковую модель

Фонемный подход сегодня — это не отдельная технология, а важный компонент в hybrid-системах, особенно для low-resource языков и улучшения интерпретируемости моделей.

Что с антиспуфингом?
    Спуфинг (spoofing) — попытка обмана биометрической системы с использованием:
Replay (перезапись): Воспроизведение записи голоса целевого спикера
Text-to-Speech (TTS): Синтетическая речь, созданная нейросетями
Voice Conversion (VC): Преобразование голоса атакующего в голос цели
Impersonation: Имитация голоса человеком
Deepfake аудио: Современные генеративные модели (VALL-E, Voicebox)

Риски:
Взлом банковских систем (голосовая авторизация)
Мошенничество в call-центрах
Фальсификация доказательств
Компрометация умных колонок

2 подхода к анти спуфинг
Системы на основе признаков (Feature-based)
End-to-End нейросетевые модели
Для современных генеративных моделей - **Watermarking:** встраивание скрытых меток при генерации
# Проблема: VALL-E, Voicebox, StyleTTS почти идеальны

1. Generalization проблема:
Модель обучается на известных атаках,
но новые TTS/VC системы создают unseen атаки

Решения:
- Self-supervised pretraining
- Zero-shot detection
- Ensemble из разных детекторов
- Online learning на новых атаках

2. Баланс между безопасностью и UX:
Слишком строгий детектор → много false reject (разозленные пользователи)
Слишком мягкий → security risks

# Решения:
# - Адаптивные thresholds (по риску операции)
# - Многофакторная аутентификация
# - Step-up authentication при подозрении

3. Adversarial атаки на anti-spoofing:
Атакующие пытаются обмануть сам детектор спуфинга
# Защиты:
# - Adversarial training
# - Stochastic defenses
# - Feature squeezing

Anti-spoofing — это гонка вооружений. Новые генеративные модели появляются каждый месяц. 
Успешный ML-инженер должен строить системы, которые не только детектируют известные атаки, 
но и могут обнаруживать неизвестные через аномалии и out-of-distribution детекцию.
